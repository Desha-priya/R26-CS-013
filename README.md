# R26-CS-013
An Autonomous AI-Driven Cyber Defense Platform with Multi-Layer Threat Detection and Automated Response

## Project Overview
NeuraShield is a unified, on-premises cyber defense platform with four integrated layers:
- Network Guardian: Zero-day intrusion and anomalous traffic detection
- Ransomware Killer: Endpoint behavioral monitoring and encryption prevention
- Multimodal Content Threat Detection: AI phishing and deepfake identification
- Continuous Zero-Trust Authentication: Threat-triggered behavioral re-authentication

## Repository Structure
- `/documents`          - Proposals, reports, logbooks, presentation slides
- `/src`           - Source code for all layers
- `/datasets`          - Datasets (ignored in git)
- `/models`        - Trained models
- `/tests`         - Test scripts and simulations
