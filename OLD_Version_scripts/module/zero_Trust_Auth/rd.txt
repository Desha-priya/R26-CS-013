## Description
Post-Compromise Session Protection Layer.  
Continuously monitors user behavior and triggers dynamic re-authentication or session lock when risk is elevated.

## Key Responsibilities
- User-specific behavioral profiling (keystroke, mouse, touch)
- Real-time anomaly detection
- Threat-triggered step-up authentication (face liveness, OTP)
- Adaptive risk thresholding based on session context
