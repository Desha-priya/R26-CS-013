About NeuraShield

Autonomous AI cyber-defence platform · R26-CS-013

NeuraShield is an on-premises platform in which four AI detection layers operate as one system behind this console. All processing — behavioural analysis, file protection, network inspection and content screening — runs on this computer. No data leaves the machine.

Detection Layers

Zero-Trust Authentication

Layer 3 · Core

Continuously verifies, after login, that the person using the computer is still the legitimate user. It models keystroke-timing behaviour with a Siamese BiLSTM network and confirms liveness from the webcam when a check is required, raising the assurance a session must satisfy as risk rises.

Developer — Deshapriya D.L.N.S. · IT22156556

Content Threat Detection

Layer 4

Screens communications for phishing text, deepfake video and spoofed audio using a multimodal model set (DistilBERT, a transfer-learned CNN and a ResNet audio model), with per-modality scores recorded for every verdict.

Developer — Mithara P.L.B. · IT22076670

Ransomware Killer

Layer 2

Detects ransomware by file-change rate, entropy and process behaviour, then contains it: high-confidence threats are terminated and every damaged file is rolled back from a clean versioned backup taken before the incident.

Developer — Jayasinghe J.A.D.S. · IT22293862

Network Guardian

Layer 1

Watches live network traffic flows and flags anomalies — suspicious ports, command-and-control patterns, data exfiltration — using an isolation forest and an autoencoder over flow features, without inspecting packet contents.

Developer — Uduwanage T.N. · IT22293312
